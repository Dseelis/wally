# Wally

> A fast wallpaper downloader and manager for Linux.

Wally is a terminal-based wallpaper manager written in Rust.
It lets you search, preview, download and apply wallpapers directly from your terminal.

### Features

- Wallpaper search and preview
- Random wallpaper mode
- Download wallpapers directly from the TUI
- Set wallpapers from Wally
- Wallhaven and Konachan support
- Search across multiple sources
- Download history
- Supports Hyprland, Sway, KDE Plasma and GNOME
- Image previews directly (Kitty and other)

## 🚀 Installation

### Quick Install

The easiest way to install Wally is using the official installer:

```bash
curl -fsSL https://raw.githubusercontent.com/Dseelis/wally/master/install.sh | sh
```
